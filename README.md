<h2>Overview</h2>
<p>The Learning Management System is a powerful developer tool designed to streamline the creation and management of e-learning platforms.</p>
<p><strong>Why Learning-Management-System?</strong></p>
<p>This project empowers developers to build comprehensive educational solutions with ease. The core features include:</p>
<ul class="list-disc pl-4 my-0">
<li class="my-0">🎓 <strong>Real-time Communication:</strong> Instant updates via Socket.IO enhance user engagement and interaction.</li>
<li class="my-0">🔒 <strong>Robust User Management:</strong> Streamlined authentication and role-based access control ensure secure user operations.</li>
<li class="my-0">📚 <strong>Dynamic Course Management:</strong> Easily create, edit, and retrieve courses to improve the educational experience.</li>
<li class="my-0">📊 <strong>Analytics Integration:</strong> Gain insights into user engagement and course performance for data-driven decisions.</li>
<li class="my-0">📧 <strong>Email Notifications:</strong> Automate user communication with customizable email templates for onboarding and interaction.</li>
<li class="my-0">🖼️ <strong>Seamless Media Management:</strong> Efficiently handle media with Cloudinary integration for a smooth user experience.</li>
</ul>

<h2>Getting Started</h2>
<h3>Prerequisites</h3>
<p>This project requires the following dependencies:</p>
<ul class="list-disc pl-4 my-0">
<li class="my-0"><strong>Programming Language:</strong> TypeScript</li>
<li class="my-0"><strong>Package Manager:</strong> Npm</li>
</ul>
<h3>Installation</h3>
<p>Build Learning-Management-System from the source and intsall dependencies:</p>
<ol>
<li class="my-0">
<p><strong>Clone the repository:</strong></p>
<pre><code class="language-sh">❯ git clone https://github.com/Harley2003/Learning-Management-System
</code></pre>
</li>
<li class="my-0">
<p><strong>Navigate to the project directory:</strong></p>
<pre><code class="language-sh">❯ cd Learning-Management-System
</code></pre>
</li>
<li class="my-0">
<p><strong>Install the dependencies:</strong></p>
</li>
</ol>
<p><strong>Using <a href="https://www.npmjs.com/">npm</a>:</strong></p>
<pre><code class="language-sh">❯ npm install
</code></pre>
